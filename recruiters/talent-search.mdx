Le moteur de recherche de talents Elite est l'outil principal des recruteurs sur Xera 1. Il vous donne accès aux profils complets des builders vérifiés et vous permet de filtrer selon des critères basés sur la performance réelle, pas les affirmations.

## Prérequis

Vous devez disposer de l'[accès Elite](/recruiters/elite-access) pour utiliser le moteur de recherche de talents.

## Interface de recherche

Depuis votre tableau de bord recruteur, accédez à l'onglet **Recherche de talents**. L'interface principale comprend :

- Une barre de recherche textuelle (recherche par nom, domaine ou mot-clé)
- Un panneau de filtres à gauche
- Les résultats avec les cartes de profil à droite

## Filtres disponibles

<ParamField body="Domaine d'activité" type="enum">
  Filtrez les builders par domaine principal : `Developer`, `Creator`, `Entrepreneur`, `Student`, `Other`.
</ParamField>

<ParamField body="Score de constance" type="range">
  Définissez un score minimum de constance sur 30 jours (0 à 100). Recommandé : ≥70 pour les builders actifs.
</ParamField>

<ParamField body="Badge vérifié" type="boolean">
  Afficher uniquement les builders avec le badge **Verified Builder** (60 jours actifs sur 90 jours).
</ParamField>

<ParamField body="ARCs actifs" type="boolean">
  Filtrer pour ne montrer que les builders ayant au moins un ARC actif en ce moment.
</ParamField>

<ParamField body="Étape de projet" type="enum">
  Recherchez des builders à une étape spécifique : `Prototype`, `Demo`, `Beta`, `Launch`.
</ParamField>

<ParamField body="Série minimale" type="number">
  Nombre minimum de jours consécutifs de publication de Traces.
</ParamField>

## Comprendre les cartes de profil

Chaque résultat affiche une carte de profil avec :

| Élément | Description |
| --- | --- |
| **Avatar et nom** | Nom affiché et lien vers le profil complet |
| **Domaine** | Domaine d'activité principal |
| **Score de constance** | Score sur 30 jours en pourcentage |
| **Série active** | Nombre de jours consécutifs actuels |
| **ARCs actifs** | Nombre d'ARCs en cours |
| **Badge vérifié** | ✓ si le builder a le badge Verified Builder |
| **Dernière Trace** | Extrait de la dernière mise à jour publiée |

## Contacter un builder

Depuis la carte de profil, cliquez sur **Envoyer un message** pour ouvrir une conversation directe. Avec l'accès Elite, votre message est marqué comme **Prioritaire** et apparaît en tête de la boîte de réception du builder.

<Tip>
  Personnalisez votre premier message en mentionnant un ARC ou une Trace spécifique du builder. Les messages personnalisés obtiennent un taux de réponse significativement plus élevé.
</Tip>

## Sauvegarder une recherche et configurer des alertes

Pour sauvegarder votre configuration de filtres :

1. Configurez vos filtres comme souhaité
2. Cliquez sur **Sauvegarder cette recherche**
3. Donnez un nom à votre recherche sauvegardée
4. Optionnellement, activez les **Alertes** pour être notifié lorsque de nouveaux builders correspondent à vos critères

Vos recherches sauvegardées sont accessibles depuis **Tableau de bord recruteur → Mes recherches**.
