Les notifications de Xera 1 vous informent en temps réel des interactions importantes sur votre compte. Vous pouvez contrôler précisément quels événements déclenchent une alerte depuis les Paramètres de notification.

## Types de notifications

| Événement | Notification push | In-app |
| --- | --- | --- |
| Nouveau(velle) abonné(e) | ✓ | ✓ |
| J'aime sur une Trace | ✓ | ✓ |
| Commentaire sur une Trace | ✓ | ✓ |
| Réponse à un commentaire | ✓ | ✓ |
| Nouveau message direct | ✓ | ✓ |
| Builder suivi passe en direct | ✓ | ✓ |
| Jalon complété (votre compte) | ✗ | ✓ |
| Badge de Trajectory débloqué | ✗ | ✓ |

## Gérer vos préférences de notification

Allez dans **Paramètres → Notifications** pour activer ou désactiver chaque type de notification indépendamment.

<Steps>
  <Step title="Ouvrir les paramètres">
    Appuyez sur votre avatar et sélectionnez **Paramètres**.
  </Step>
  <Step title="Sélectionner Notifications">
    Dans le menu de gauche, appuyez sur **Notifications**.
  </Step>
  <Step title="Activer ou désactiver les types">
    Utilisez les bascules pour activer ou désactiver chaque catégorie de notification.
  </Step>
  <Step title="Enregistrer">
    Les modifications prennent effet immédiatement.
  </Step>
</Steps>

## Activer les notifications push du navigateur

Xera 1 est une PWA. Les notifications push fonctionnent directement dans le navigateur sans installation depuis un app store.

<Note>
  Pour recevoir des notifications push, vous devez autoriser Xera 1 dans les paramètres de notification de votre navigateur. Xera 1 demande cette permission lors de votre première connexion.
</Note>

Si vous avez précédemment refusé les notifications push :

<Tabs>
  <Tab title="Chrome / Edge">
    1. Cliquez sur l'icône de cadenas à gauche de l'URL dans la barre d'adresse.
    2. Sélectionnez **Paramètres du site**.
    3. Trouvez **Notifications** et changez la valeur sur **Autoriser**.
    4. Rechargez la page.
  </Tab>
  <Tab title="Firefox">
    1. Cliquez sur le bouton de permission (icône bouclier ou cadenas) à gauche de l'URL.
    2. Cliquez sur la flèche **\>** à côté des **Permissions**.
    3. Trouvez **Recevoir des notifications** et cliquez sur **Autoriser**.
    4. Rechargez la page.
  </Tab>
  <Tab title="Safari">
    1. Allez dans **Safari → Paramètres → Sites web → Notifications**.
    2. Trouvez `xera1.xyz` dans la liste.
    3. Changez la valeur sur **Autoriser**.
  </Tab>
</Tabs>

## Réinitialiser toutes les préférences

Pour revenir aux paramètres de notification par défaut, allez dans **Paramètres → Notifications** et appuyez sur **Réinitialiser par défaut** en bas de page.
