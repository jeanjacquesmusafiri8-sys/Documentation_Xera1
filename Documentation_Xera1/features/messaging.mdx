La messagerie privée sur Xera 1 vous permet de contacter directement d'autres builders, de collaborer sur des projets, de partager des ressources et de nouer des relations sans quitter la plateforme.

## Comment fonctionne la messagerie

Vous pouvez envoyer un message direct à :

- **Tout builder que vous suivez** si ce builder vous suit en retour (abonnement mutuel)
- **Tout builder ayant un profil public** si la messagerie publique est activée dans ses paramètres

## Envoyer un message

<Steps>
  <Step title="Ouvrir la messagerie">
    Appuyez sur l'icône **Message** dans la barre de navigation.
  </Step>
  <Step title="Créer une nouvelle conversation">
    Appuyez sur **Nouveau message** et recherchez le builder par nom d'utilisateur.
  </Step>
  <Step title="Rédiger votre message">
    Saisissez votre message. Vous pouvez joindre des images ou des liens.
  </Step>
  <Step title="Envoyer">
    Appuyez sur **Envoyer**. Le destinataire reçoit une notification push.
  </Step>
</Steps>

## Types de contenu dans les messages

| Type | Pris en charge |
| --- | --- |
| Texte | ✓ |
| Images (JPEG, PNG, GIF) | ✓ |
| Liens | ✓ (aperçu automatique) |
| Vidéos | Bientôt disponible |
| Fichiers | Bientôt disponible |

## Paramètres de messagerie

Depuis **Paramètres → Messagerie**, vous pouvez configurer :

<Accordion title="Qui peut vous envoyer un message">
  Choisissez entre **Uniquement les abonnements mutuels** (par défaut) ou **Tout le monde** (profil public ouvert).
</Accordion>

<Accordion title="Notifications de message">
  Activez ou désactivez les notifications push pour les nouveaux messages.
</Accordion>

<Accordion title="Demandes de message">
  Les messages de builders que vous ne suivez pas arrivent dans l'onglet **Demandes**. Acceptez ou refusez chaque demande avant de recevoir les futurs messages de cet utilisateur.
</Accordion>

## Signaler un message

Si vous recevez un message inapproprié, appuyez longuement sur le message et sélectionnez **Signaler**. Choisissez la raison parmi les options proposées et confirmez. L'équipe de modération de Xera 1 examine tous les signalements.

<Warning>
  Ne partagez jamais vos informations personnelles sensibles (mot de passe, numéro de carte, code d'accès) dans les messages privés. Xera 1 ne vous contactera jamais pour vous demander ces informations.
</Warning>
