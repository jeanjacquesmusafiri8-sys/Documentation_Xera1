La recherche de Xera 1 vous permet de trouver des builders spécifiques, de découvrir des ARCs dans votre domaine d'intérêt, et de retrouver des Traces par mots-clés. Que vous cherchiez de l'inspiration, des collaborateurs ou des builders à suivre, la recherche est votre point de départ.

## Types de recherche

La barre de recherche principale, accessible depuis l'onglet **Rechercher** dans la barre de navigation, couvre trois catégories :

### Builders

Recherchez par nom d'utilisateur ou par domaine d'activité.

| Signal de classement | Description |
| --- | --- |
| Score de constance | Les builders avec un score de Trajectory élevé apparaissent en tête |
| Correspondance exacte | Les noms d'utilisateur correspondants exactement sont toujours priorisés |
| Badge vérifié | Les comptes vérifiés sont mis en avant dans les résultats |

### ARCs

Recherchez des projets par titre, description ou étape (Idée, Prototype, Démo, Bêta, Lancement).

Exemple de requête : `"saas bêta"` ou `"rust apprentissage"`.

### Traces

Recherchez des mises à jour de preuve de travail par mot-clé. Les résultats incluent les Traces des builders vérifiés et non vérifiés.

## Filtres de recherche

Après une recherche, appuyez sur le bouton **Filtres** pour affiner vos résultats :

<Accordion title="Filtrer par domaine d'activité">
  Restreindre les résultats à : Developer, Creator, Entrepreneur, Student ou Other.
</Accordion>

<Accordion title="Filtrer par badge">
  Afficher uniquement les builders avec le badge **Verified Builder**.
</Accordion>

<Accordion title="Filtrer par étape d'ARC">
  Trouver des ARCs à une étape spécifique du cycle de vie.
</Accordion>

<Accordion title="Trier par">
  Choisir entre **Pertinence** (par défaut), **Le plus récent** ou **Score de constance**.
</Accordion>

## Recherche de talents pour recruteurs

Si vous êtes recruteur avec accès Elite, vous avez accès à une interface de recherche de talents avancée avec des filtres supplémentaires. Consultez la page [Recherche de talents](/recruiters/talent-search) pour les détails.
