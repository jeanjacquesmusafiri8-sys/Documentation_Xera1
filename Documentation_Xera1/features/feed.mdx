Le feed de Xera 1 est votre fenêtre sur la communauté des builders. Il combine en temps réel les Traces des personnes que vous suivez avec un moteur de découverte qui met en avant les builders les plus engagés de la plateforme.

## Deux types de contenu dans votre feed

### Feed abonnements

Le feed **Abonnements** est chronologique. Il affiche uniquement les Traces publiées par les builders que vous suivez, dans l'ordre de publication. Pas d'algorithme, pas de surprises.

### Feed découverte

Le feed **Découverte** est personnalisé par algorithme. Il vous montre des builders, des ARCs et des Traces que vous n'avez pas encore découverts.

La composition du feed Découverte :

| Segment | Proportion |
| --- | --- |
| Builders vérifiés actifs | 65 % |
| Builders émergents avec élan | 35 % |

<Info>
  Le feed découverte exclut les comptes inactifs depuis plus de 14 jours, ce qui garantit que les Traces que vous voyez reflètent un effort actuel, pas des archives.
</Info>

## Signaux d'algorithme

L'algorithme de découverte classe les Traces selon plusieurs signaux :

- **Score de constance** : les builders avec une haute fréquence de publication sont prioritaires
- **Élan de la Trajectory** : les builders dont l'activité s'accélère remontent dans le feed
- **Engagement** : les j'aime et les commentaires amplifient la portée d'une Trace
- **Correspondance de domaine** : si vous avez configuré un domaine d'activité, vous verrez plus de builders dans le même domaine

## Filtrer et personnaliser votre feed

Depuis l'onglet **Découverte**, appuyez sur l'icône de filtre pour affiner ce que vous voyez :

<Accordion title="Filtrer par domaine">
  Limitez votre feed à un domaine d'activité spécifique : Developer, Creator, Entrepreneur, Student ou Other.
</Accordion>

<Accordion title="Filtrer par étape d'ARC">
  Voyez uniquement les Traces d'ARCs à une étape spécifique : Prototype, Démo, Bêta ou Lancement.
</Accordion>

## Interagir dans le feed

Chaque Trace dans le feed vous permet de :

- **Aimer** : appuyez sur l'icône cœur pour montrer votre appréciation
- **Commenter** : laissez une réponse ou posez une question
- **Partager** : copiez un lien vers la Trace pour la partager en dehors de la plateforme
- **Suivre l'auteur** : appuyez sur son avatar pour voir son profil et l'ajouter à votre feed Abonnements

## Algorithme de recommandation et vie privée

Xera 1 utilise les signaux d'engagement et de domaine pour personnaliser votre feed. Ces signaux sont basés uniquement sur votre activité sur la plateforme. Vous pouvez réinitialiser votre fil de recommandations depuis **Paramètres → Confidentialité → Réinitialiser les préférences du feed**.
