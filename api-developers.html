API et Intégrations Développeurs

Cette section documente le statut actuel de l'infrastructure API de XERA1 et les règles applicables aux développeurs.

1. Statut de l'API Publique pour les Tiers

Information importante : Aucune API publique pour les tiers n'est actuellement ouverte.
  • Pas de clés API tiers : Il n'existe pas de système de gestion ou de génération de `API_KEY` pour les applications externes.
  • Pas de serveur OAuth2 tiers : Les applications tierces ne peuvent pas utiliser XERA1 comme fournisseur d'identité OAuth2 pour le moment.
  • Pas de rate limiting tiers public : Les règles d'accès développeurs externes ne sont pas encore publiées.

2. Endpoints `/api/*` Internes

L'application web XERA1 consomme des endpoints REST sous `/api/*` (ex: `/api/ask`, `/api/health`, endpoints Supabase).

Ces routes sont des API REST internes exclusivement réservées au fonctionnement de l'application web XERA1. Elles sont sécurisées par session et ne doivent pas être appelées par des scripts ou intégrations externes non autorisés.
