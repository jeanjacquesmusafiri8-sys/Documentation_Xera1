L'API Feed vous permet de récupérer les Traces publiées sur Xera 1 depuis le fil de découverte, les abonnements d'un compte, ou le profil d'un builder spécifique. Ces endpoints sont idéaux pour intégrer le contenu Xera 1 dans vos dashboards, outils d'analyse ou applications tierces.

## GET /feed/discover

Retourne les Traces du fil de découverte, triées par algorithme de pertinence.

```bash
GET https://api.xera1.xyz/v1/feed/discover
Authorization: Bearer YOUR_API_TOKEN
```

### Paramètres de requête

<ParamField query="limit" default="20" type="integer">
  Nombre de Traces à retourner (max 50).
</ParamField>

<ParamField query="cursor" type="string">
  Curseur de pagination pour la page suivante.
</ParamField>

<ParamField query="domain" type="string">
  Filtrer par domaine d'activité : `developer`, `creator`, `entrepreneur`, `student`, `other`.
</ParamField>

### Réponse

    "cursor": "cursor_next_abc",

## GET /feed/following

Retourne les Traces des builders suivis par l'utilisateur authentifié, en ordre chronologique inverse.

```bash
GET https://api.xera1.xyz/v1/feed/following
Authorization: Bearer YOUR_API_TOKEN
```

**Scope requis** : `read:traces`

### Paramètres de requête

<ParamField query="limit" default="20" type="integer">
  Nombre de Traces à retourner (max 50).
</ParamField>

<ParamField query="cursor" type="string">
  Curseur de pagination.
</ParamField>

---

## GET /profiles/{username}/traces

Retourne les Traces publiées par un builder spécifique.

```bash
GET https://api.xera1.xyz/v1/profiles/{username}/traces
Authorization: Bearer YOUR_API_TOKEN
```

### Paramètres de chemin

<ParamField path="username" type="string" required>
  Le nom d'utilisateur du builder (sans `@`).
</ParamField>

### Paramètres de requête

<ParamField query="limit" default="20" type="integer">
  Nombre de Traces à retourner (max 50).
</ParamField>

<ParamField query="cursor" type="string">
  Curseur de pagination.
</ParamField>

<ParamField query="arc_id" type="string">
  Filtrer les Traces d'un ARC spécifique.
</ParamField>

---

## POST /traces

Publie une nouvelle Trace au nom de l'utilisateur authentifié.

```bash
POST https://api.xera1.xyz/v1/traces
Authorization: Bearer YOUR_API_TOKEN
Content-Type: application/json
```

**Scope requis** : `write:traces`

### Corps de la requête

<ParamField body="content" type="string" required>
  Le texte de la Trace (max 1 000 caractères).
</ParamField>

<ParamField body="arcId" type="string">
  L'ID de l'ARC auquel cette Trace est liée.
</ParamField>

<ParamField body="progressPercent" type="integer">
  Pourcentage de progression du jalon associé (0 à 100).
</ParamField>

### Exemple

```json
{
  "content": "Implémentation du système de retry avec backoff exponentiel. Testé sur 500 requêtes simulées.",
  "arcId": "arc_def456",
  "progressPercent": 65
}
```

### Réponse

```json
{
  "success": true,
  "data": {
    "id": "trace_new789",
    "content": "Implémentation du système de retry avec backoff exponentiel. Testé sur 500 requêtes simulées.",
    "publishedAt": "2025-01-15T16:45:00Z",
    "arcId": "arc_def456",
    "progressPercent": 65
  }
}
```
